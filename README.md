---

## 🚀 Quick Start: Deploy to GitHub Pages in 60 Seconds

You can host this application completely free on GitHub Pages:

### Method 1: Web Interface (No Git required)
1. Create a new repository on GitHub (e.g., `blueprint-studio`).
2. Click **Add file** > **Upload files** and drag `index.html` (or the contents of this zip) into the repository.
3. Commit the changes to `main`.
4. Go to **Settings** > **Pages** (under Code and automation in the left sidebar).
5. Under **Build and deployment** > **Branch**, select `main` and `/ (root)`, then click **Save**.
6. Within 30 seconds, your CAD studio is live at:  
   `https://<your-username>.github.io/blueprint-studio/`

### Method 2: Command Line (Git CLI)
```bash
git init
git add .
git commit -m "Initial commit: Blueprint Studio CAD & Vector Suite"
git branch -M main
git remote add origin https://github.com/<your-username>/blueprint-studio.git
git push -u origin main
```
Then enable GitHub Pages under repository Settings > Pages.
